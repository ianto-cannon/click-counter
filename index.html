About this pattern

The pattern is a Maurer rose r = sin(nθ) with n = . We draw straight lines between points on the rose curve at angles θ = kn radians, for k = 1, 2, 3, ... 512.

In this pattern, the angle θ between each point is mod 2π, which is of a full turn, while the phase nθ advances by ² mod 2π, which is of a turn. Since π is irrational, these values never repeat for different integers n, and the same pattern is never drawn twice.

Change the number in the address bar to see the rose for any other count.
